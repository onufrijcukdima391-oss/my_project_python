Інтерактивний урок: перевірка умов у Python

📘 Теорія

if — перевіряє умову.

elif — перевіряє іншу умову, якщо попередня хибна.

else — виконується, якщо жодна попередня умова не підійшла.

age = 15

if age >= 18:
    print("Повнолітній")
elif age >= 14:
    print("Підліток")
else:
    print("Дитина")
